# ТВ-4 Шкыльнык — передача проекта на другой компьютер

Это подарок брату для учебного токарного станка ТВ-4. Сенсорная панель измеряет обороты шпинделя, ведёт статистику и подсказывает, как выставить механические рычаги. Пуск, останов, реверс, аварийный останов и задание частоты выполняет отдельная аппаратура станка. Прошивка ESP32 команд приводу не передаёт.

Продолжайте работу в **`main`** закрытого репозитория `bangkok13/tv4-digital-control`. На подарочную плату по Micro-USB записан **`v2.1.0`**, коммит прошивки **`005a9e6`**. Старая ветка `development/v2.0` остановилась на `v2.0.0`. Готовый архив содержит образы и манифест. [Выпуск 2.1.0](release/TV4-Digital-v2.1.0.zip) · [README](README.md)

## Что увидит брат

- Семь секунд при включении видны фотография мотоцикла, «6 VOLT GARAGE» и «С ДР, БРО!». Затем открывается тахометр с заголовком **«TV-4 Шкыльнык»**. Справа **D** означает DEMO, **L** означает LIVE. Новая панель начинает в DEMO, настроенная восстанавливает сохранённый режим.
- Главный экран показывает обороты, скорость резания и состояние измерения. Есть графики за 30 секунд, 2 и 10 минут, моточасы, пуски, время питания и четыре последние операции. В DEMO доступны автоматический цикл и ползунок. Его показания отделены от реальной статистики.
- В меню есть калькуляторы точения, проточки, подачи и резьбы. Справочник объединяет переднюю бабку с коробкой скоростей в один узел. Ещё два рисунка показывают коробку подач и фартук. Девять нажимаемых букв размещены прямо на рукоятках. Расчёты и рисунки доступны без Wi-Fi и microSD. [Калькуляторы](docs/calculators.md) · [Рисунки и обозначения](docs/tv4-controls.md)
- В **«Меню → Резьбы → Параметры → Результат»** по диаметру, шагу, направлению, типу резьбы, материалу и резцу выводятся положения ручек и целевые обороты. В «Обороты» цель можно сравнить с датчиком LIVE. Процент внешней ручки появляется для выбранной ступени только между двумя сохранёнными измерениями. Геометрия профиля `H` и `d2` вынесена в «Параметры → Размеры». [Пример M10 × 1,25 на экране](docs/thread-v2.1.png) · [Как работает расчёт](docs/threading.md)

Для этой панели владелец выбрал ростовский шильдик с шестью скоростями **120 / 180 / 250 / 390 / 500 / 710 об/мин** и тремя шагами **0,8 / 1,0 / 1,25 мм**. Табличка на конкретном станке у брата ещё не сфотографирована. Если она отличается, сначала сверьте таблицы и рисунки с фотографией. [Принятый шильдик и источники](docs/tv4-controls.md)

## Что подключено и что лежит отдельно

| Узел | Подключение и состояние |
| --- | --- |
| Панель на столе | Двухпортовая ESP32-2432S028, ESP32-D0WD-V3 ревизии 3.1, Flash 4 МиБ. Экран ST7789 240 × 320 и резистивный тач XPT2046 проверены. Рабочий профиль `panel-st7789`. Через Micro-USB определяется как CH340 `1A86:7523`. На прежнем ПК это был `COM3`. |
| Датчик оборотов | Вход панели — `IO27` на `CN1`, логика 0–3,3 В. Для полевого датчика LJ12A3-4-Z/BX (NPN NO) предусмотрены отдельное питание и согласование выхода с ESP32. LM2596S понижает напряжение питания. Для передачи импульсов нужен отдельный согласующий вход. Маркировку экземпляра и напряжение на выходе согласователя предстоит проверить. |
| Ручка и джойстик | Рабочая ручка относится к аналоговому входу частотника ESQ-230-4T-2.2K. В схеме проекта для него выбран линейный потенциометр 4,7 кОм. Купленный WH148 B10K описан в настольном опыте с мультиметром. Панель рассчитывает рекомендуемую отметку ручки по двум измерениям. Джойстик XD5-PA12 относится к аппаратной схеме привода. Для опыта с тахометром достаточно панели и источника импульсов. |

Распиновка дисплея, тача и тахометра собрана в одном заголовке. Для подключения конкретного согласователя и выбора потенциометра частотника используйте схему стенда и указанное там руководство привода. [Распиновка в коде](include/tv4_board.h) · [Плата и USB](docs/hardware.md) · [Стенд, питание, ручка и датчик](docs/wiring.md)

## Как начать на новом ПК

Нужны Git с доступом к закрытому репозиторию и Python. Для новой копии в Windows PowerShell выполните команды ниже. Если репозиторий уже клонирован, откройте его, выполните `git switch main` и `git pull --ff-only`. Плата для сборки не требуется.

```powershell
git clone https://github.com/bangkok13/tv4-digital-control.git
Set-Location tv4-digital-control
git show -s --oneline v2.1.0
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install platformio==6.1.19
$pio = (Resolve-Path .\.venv\Scripts\pio.exe).Path
& $pio run -e panel-st7789
```

Для сеанса с подарочной платой подключите её кабелем данных к Micro-USB. Команда `device list` покажет порт этого компьютера. При необходимости обновить панель на столе используйте следующие команды. Выход из монитора — `Ctrl+C`.

```powershell
& $pio device list
$panelPort = Read-Host 'COM-порт платы CH340'
& $pio run -e panel-st7789 -t upload --upload-port $panelPort
& $pio device monitor --port $panelPort --baud 115200
```

В проекте закреплены Espressif32 6.12.0, Arduino-ESP32 2.0.17, TFT_eSPI 2.5.43 и LVGL 8.3.11. Для локальных тестов нужны CMake и компилятор C++17. В инструкции приведены команды сборки и запуска трёх наборов CTest. При переносе с прошивки 1.x на 2.x первая установка идёт по USB с таблицей разделов. На подарочной плате новая разметка уже установлена. [Профили](platformio.ini) · [Тесты](docs/testing.md) · [Прошивка и восстановление](docs/flash.md)

## Что уже проверено и с чего продолжить

**На подарочной ESP32** для `v2.1.0` команда `verify_flash` сверила все 1 285 792 байта приложения. После перезапуска в журнале были `NVS=ok cal=1` и открытие тахометра. Цвета и слежение тача за пальцем владелец проверял на этой плате при первичной настройке. На компьютере прошли `core`, `storage` и `ui`, включая два миллиона интервалов тахометра, 300 циклов навигации и нажатия на все девять букв. На `v2.0.0` отдельная стендовая сборка на ESP32 проверила запись по Web OTA и ArduinoOTA с двумя перезагрузками. Клиент теста работал на самой ESP32. [Проверки 2.1.0](docs/testing.md) · [Отчёт о стенде OTA 2.0.0](docs/final-report.md)

1. **Первый опыт на столе** — включить LIVE и подать на `IO27` согласованный сигнал известной частоты. При 10 Гц и настройке 1 импульс/оборот ожидаются 600 об/мин, при 2 импульсах/оборот — 300. После снятия сигнала дождаться «Н/Д». Для опыта без генератора в схеме стенда есть вариант с кнопкой. [Порядок подключения](docs/wiring.md)
2. **На станке у брата** — сверить шильдик и положения рычагов, проверить реальный датчик по независимому тахометру. Затем записать две точки ручки в LIVE для каждой используемой механической ступени. Эти значения индивидуальны. [Резьбы и калибровка ручки](docs/threading.md)
3. **В мастерской** — проверить связь с телефоном и роутером, приём в закрытом шкафу и устойчивость тахометра при работе привода. Для испытания OTA привод обесточивают, питание панели сохраняют. [Оставшиеся проверки](docs/open-questions.md)
