# Что проверить на конкретном станке

| Вопрос | Что можно установить на стенде | Что нужно в мастерской |
| --- | --- | --- |
| Модификация механики | Для подарочной панели выбран ростовский шильдик 120/180/250/390/500/710. На чертеже девять органов с буквой на рукоятке | Когда станок будет доступен, сопоставить его табличку и ход каретки с образцом |
| Левая резьба | Справочник различает руку и направление переноса через трензель | На обесточенном приводе проверить фактический ход и принятый способ установки инструмента |
| Тахометр LIVE | Формулы, тайм-ауты, PPR, фильтр и пропуски проверяются эталонными фронтами в тестах | Маркировка датчика, согласователь NPN на 3,3 В, осциллограмма, реальный зазор и сравнение с независимым тахометром |
| Режим резания | Для точения Vc вводится вручную. Для резьбы есть справочный расчёт по материалу и резцу | Сверить конкретный инструмент, марку сплава, доступный выход и допустимую скорость |
| Шкала B5K | Интерполяция двух измерений и отсечение значений вне их интервала проверены на стенде программы | Снять две реальные точки LIVE для используемой ступени на частотнике брата |
| Связь в шкафу | Временная защищённая точка настройки, адрес на TFT | Телефон или роутер 2,4 ГГц. Проверить RSSI при закрытой металлической двери, вход STA, браузер с телефона и доставку espota |
| Длительная эксплуатация | В программе ограничены периоды записи NVS, история фиксированного объёма | Проверить шумы при реальном приводе, нагрев и длительную работу |

Карта microSD для текущего комплекта иллюстраций и справочника не требуется. Данные карты не затрагиваются.
