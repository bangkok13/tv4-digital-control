# Проверка панели 2.1

Версия 2.1.0 записана по USB на двухпортовую ESP32-2432S028 со ST7789. Команда `verify_flash` сверила все 1 285 792 байта приложения. После перезапуска панель сообщила версию 2.1.0, `NVS=ok cal=1` и открыла тахометр. Все три набора CTest прошли. На экране LVGL проверены попадания по девяти буквам и отсутствие обрезанных подписей. Резьба на физическом станке и реальные метки B5K остаются для проверки в мастерской.

## На компьютере

Сначала соберите `pio run -e panel-st7789`, чтобы получить закреплённые исходники LVGL. С CMake 3.16+ и компилятором C++17:

```powershell
cmake -S test -B .pio/host -DLVGL_DIR="$PWD/.pio/libdeps/panel-st7789/lvgl"
cmake --build .pio/host --config Release
ctest --test-dir .pio/host -C Release --output-on-failure
```

| Набор | Что проверяется |
| --- | --- |
| core | Отбрасывание помех, PPR, 1 RPM, потеря сигнала, переполнение, два миллиона интервалов, разделение DEMO/LIVE, ручной RPM, расчёты и недопустимые значения, все окна графиков, границы разрешения OTA после физического импульса |
| storage | Восстановление старого формата, совместимость настроек и моточасов, последние операции и время питания через перезагрузку, ограничение записи, отмена сброса при ошибке NVS, повтор записи |
| ui | Кадровый буфер LVGL 240 × 320 и драйвер касаний. Проверяются все девять букв прямо на ручках, ширина подписей, рецепт M10, недоступный шаг, таблицы шильдика, ввод двухточечной шкалы, 300 циклов навигации и память |

Для шильдика ядро сверяет положения обеих скоростных рукояток на шести ступенях, три положения шага, выбор целевых оборотов и случай ниже 120. Для ручки проверяются интерполяция, обратная характеристика, раздельность ступеней, недоступность процента за границами замеров и запрет записи из DEMO. Набор storage проверяет перезапуск и отказ записи NVS.

Основной и альтернативный TFT, две диагностики и профиль espota собираются обычным PlatformIO. `tools/package_release.py` сравнивает загрузчики и таблицы, проверяет двоичные записи NVS/OTA, вместимость обоих слотов, перечитывает архив и включает SHA-256 приложений.

Тест `python test/test_web.py "путь/к/Chrome"` исполняет встроенную веб-страницу в Chromium на локальном HTTP-стенде. Он проверяет видимые RPM, режим, моточасы и очистку показаний при потере связи. Для этой проверки достаточно Python 3.10+ и Chrome либо Edge.

## На изолированной плате

Убедитесь по USB-идентификатору, модели/ревизии ESP, MAC известной платы, объёму Flash и профилю TFT, что выбран нужный экземпляр. Перед первым переходом можно локально сохранить 0x5000 байт NVS с адреса 0x9000. Для проверки меню без физического экрана используется компьютерный стенд. Реальное изображение и попадание пальца по углам требуют наблюдателя.

Специальная сборка `bench-network-st7789` выполняет сетевые испытания только по явной команде USB. На столе должен находиться отдельно запитанный ESP32, привод должен быть физически обесточен. После появления главного экрана отправьте по Serial 115200 строчную `t` для Web OTA или `a` для ArduinoOTA. Тест использует локальный IP самой ESP32, штатную аутентификацию и отправляет копию своего запущенного приложения в свободный слот. Каждая успешная запись приводит к перезапуску. На обычном профиле эти команды отсутствуют. Установите штатный `panel-st7789` по USB после завершения теста.

## На станке и в сети мастерской

1. Телефоном откройте точку настройки с TFT, введите параметры тестовой сети 2,4 ГГц, закройте точку. Проверьте подключение STA, восстановление после краткого отключения роутера, IP и RSSI.
2. На входе LIVE сначала проверьте согласованные импульсы от заведомо известного источника. При 10 Гц и одной метке ожидаются 600 RPM. При двух метках ожидаются 300 RPM. Снятие сигнала должно приводить к «Н/Д».
3. Сверьте механические рычаги с табличкой станка, направление движения и обороты с независимым тахометром. Сравните моточасы после сохранения и перезагрузки. Запишите длительный лог с RAM и потерями очереди.
4. Для испытания обновлений через роутер обесточьте привод, сохраните питание панели и разрешите OTA на TFT. Сравните версию и выбранный слот по Serial после перезапуска. [Порядок обновления](ota.md) · [Фактический отчёт](final-report.md)
