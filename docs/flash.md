# Прошивка из бинарного выпуска 2.1.0

Распакуйте ZIP в один каталог. Для подтверждённой двухпортовой платы нужен `panel-st7789.bin`. Для новой ревизии сначала используйте соответствующий discovery-профиль. Общие файлы загрузки соответствуют классическому ESP32 с Flash 4 МиБ и двум OTA-слотам. При переходе с 1.0.4 записывайте через USB загрузчик, таблицу разделов, начальное состояние otadata и приложение. Архив содержит контрольные суммы SHA-256.

1. Подключите плату к ПК одним кабелем передачи данных. Для этих команд установите `python -m pip install esptool==4.9.0` в виртуальное окружение. Командой `python -m serial.tools.list_ports -v` определите порт и подставьте его вместо COM7.
2. Из каталога архива прочитайте идентификатор и ёмкость Flash. Для подтверждённых 4 МиБ сохраните заводской образ.

   ```powershell
   python -m esptool --chip esp32 --port COM7 flash_id
   python -m esptool --chip esp32 --port COM7 read_flash 0x0 0x400000 factory-backup.bin
   ```

3. Загрузите диагностическую прошивку. Адреса ниже оставляют область NVS 0x9000…0xDFFF между записываемыми блоками.

   ```powershell
   python -m esptool --chip esp32 --port COM7 --baud 460800 write_flash 0x1000 bootloader.bin 0x8000 partitions.bin 0xe000 boot_app0.bin 0x10000 discovery-st7789.bin
   ```

4. Убедитесь, что видна надпись **TV-4 DIGITAL**, цвета идут в порядке красный, зелёный, синий. Нажмите и отпустите каждый из четырёх прицелов, затем проверьте след по краям. USB-лог работает на 115200 бод. Если подтверждён профиль ILI9341, выберите диагностический и основной файлы с суффиксом `ili9341`.
5. Установите основной профиль. Эта команда выбирает первый OTA-слот даже после предыдущего обновления по сети. Область NVS с калибровкой и данными не попадает в диапазоны записи.

   ```powershell
   python -m esptool --chip esp32 --port COM7 --baud 460800 write_flash 0x1000 bootloader.bin 0x8000 partitions.bin 0xe000 boot_app0.bin 0x10000 panel-st7789.bin
   ```

После включения или RST на семь секунд появляется фотография мотоцикла с надписями «6 VOLT GARAGE» и «С ДР, БРО!». Затем открывается «TV-4 Шкыльнык». Метка справа показывает D для DEMO или L для LIVE. На чистой плате выбирается DEMO. В LIVE при отключённом датчике ожидаются «Н/Д» и постоянные моточасы. Для восстановления 1.0.4 используйте три загрузочных файла и соответствующее приложение именно из архива 1.0.4. Данные, записанные только в формате 2.0, старая прошивка не читает.
