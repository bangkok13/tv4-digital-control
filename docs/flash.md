# Прошивка из бинарного выпуска 1.0.0

Распакуйте ZIP в один каталог. Для платы с Micro-USB и USB-C на фотографии первый кандидат — `discovery-st7789.bin`. Три общих файла загрузки соответствуют разметке PlatformIO `esp32dev` для классического ESP32 с Flash 4 МиБ. Файлы приложения в архиве начинаются по адресу **0x10000**.

1. Подключите плату к ПК одним кабелем передачи данных. Для этих команд установите `python -m pip install esptool==4.9.0` в виртуальное окружение. Командой `python -m serial.tools.list_ports -v` определите порт и подставьте его вместо COM7.
2. Из каталога архива прочитайте идентификатор и ёмкость Flash. Для подтверждённых 4 МиБ сохраните заводской образ.

   ```powershell
   python -m esptool --chip esp32 --port COM7 flash_id
   python -m esptool --chip esp32 --port COM7 read_flash 0x0 0x400000 factory-backup.bin
   ```

3. Загрузите диагностическую прошивку. Адреса ниже оставляют область NVS 0x9000…0xDFFF между записываемыми блоками.

   ```powershell
   python -m esptool --chip esp32 --port COM7 --baud 460800 write_flash 0x1000 bootloader.bin 0x8000 partitions.bin 0xe000 boot_app0.bin 0x10000 discovery-st7789.bin
   ```

4. Убедитесь, что видна надпись **TV-4 DIGITAL**, цвета идут в порядке красный, зелёный, синий. Нажмите и отпустите каждый из четырёх прицелов, затем проверьте след по краям. USB-лог работает на 115200 бод. Если подтверждён профиль ILI9341, выберите диагностический и основной файлы с суффиксом `ili9341`.
5. После успешного теста для уже установленной разметки запишите только приложение соответствующего профиля. Результат калибровки сохранится.

   ```powershell
   python -m esptool --chip esp32 --port COM7 --baud 460800 write_flash 0x10000 panel-st7789.bin
   ```

На первом запуске панели открывается DEMO. В LIVE при отключённом датчике ожидаются «Н/Д» и отсутствие прибавки моточасов. Готовые образы предназначены для индикации.
