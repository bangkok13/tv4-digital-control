# Идентификация платы и первый запуск

В версии 2.0 назначения GPIO и профиль дисплея сохранены. Wi-Fi использует встроенное радио, слот microSD свободен. Вход IO27 продолжает регистрировать физические фронты в DEMO для блокировки обновлений. Диагностика показывает размер Flash, полученный от ESP32. Два слота OTA рассчитаны на подтверждённый объём 4 МиБ. [Разметка и память](storage.md)

На фотографиях экземпляра видны модуль с маркировкой ESP-32, Micro-USB рядом с USB-C, microSD и заводская демонстрация в альбомной ориентации. Шлейф и расположение U3 согласуются с резистивной версией CYD. Маркировку кристалла TFT по фотографии прочитать нельзя. Для первого теста выбран профиль двухпортовой CYD. Подтверждением профиля служат изображение, правильные цвета и совпадение четырёх точек. Сохраните результат вместе с фотографиями своей платы.

Конкретная плата на стенде определилась по Micro-USB как USB-SERIAL CH340, VID:PID `1A86:7523`, COM3. Команда `flash_id` подтвердила ESP32-D0WD-V3 ревизии 3.1, кварц 40 МГц и 4 МиБ Flash (JEDEC C8:4016). Номер COM относится к этому компьютеру и может измениться.

На этом экземпляре прошла проверка `discovery-st7789`: пользователь подтвердил правильный порядок RGB и попадание метки под палец; журнал XPT2046 зарегистрировал реальные отсчёты и успешное сохранение четырёхточечной калибровки. Для этой платы выбран `panel-st7789`.

| Сборка discovery | Предполагаемая комплектация | Основание |
| --- | --- | --- |
| `discovery-st7789` | Двухпортовая 2432S028R/Rv3, ST7789 и XPT2046 | [Профиль Rv3 в PlatformIO](https://github.com/rzeldent/platformio-espressif32-sunton/blob/main/esp32-2432S028Rv3.json), [конфигурация TFT_eSPI именно для CYD2USB](https://github.com/witnessmenow/ESP32-Cheap-Yellow-Display/blob/main/DisplayConfig/CYD2USB/User_Setup.h) |
| `discovery-ili9341` | 2432S028R, ILI9341 и XPT2046 | [Профиль R в PlatformIO](https://github.com/rzeldent/platformio-espressif32-sunton/blob/main/esp32-2432S028R.json), [конфигурация TFT_eSPI](https://github.com/witnessmenow/ESP32-Cheap-Yellow-Display/blob/main/DisplayConfig/User_Setup.h) |

Оба профиля рассчитаны на классический ESP32 и Flash 4 МиБ. Платы с другим ESP, ёмкостным тачем или другой разводкой требуют собственного профиля. USB-C сам по себе не определяет контроллер. Проект использует базовую цель `esp32dev`, все назначения периферии задаёт [tv4_board.h](../include/tv4_board.h).

| Сигнал | GPIO |
| --- | --- |
| TFT HSPI, SCLK / MOSI / MISO / CS / DC | 14 / 13 / 12 / 15 / 2 |
| TFT RESET / подсветка | общий сброс / 21, активная единица |
| XPT2046 VSPI, SCLK / DIN / DOUT / CS / PENIRQ | 25 / 32 / 39 / 33 / 36 |
| Вход RPM для этих профилей | 27, CN1, вход с подтяжкой к 3,3 В; подтвердить по надписи IO27 |

GPIO12 задан по конфигурации CYD2USB TFT_eSPI. На части ST7789 линия чтения от панели не разведена. Драйвер передаёт изображение по SPI на 24 МГц. Он проверяет локальную геометрию и настройку ШИМ. Ответа об успешном выводе пикселей по этому интерфейсу нет. Тач использует отдельную шину на 2 МГц, PENIRQ и проверку давления; microSD не инициализируется. [Разъёмы и общие цепи CYD](https://github.com/witnessmenow/ESP32-Cheap-Yellow-Display/blob/main/PINS.md)

## Проверка на столе

1. Оставьте только USB с передачей данных и один источник питания. Выполните `pio device list` и сверьте появившийся порт при отключении и повторном подключении. Если экран светится, а порт отсутствует, проверьте кабель передачи данных, другой USB-разъём по одному и устройство USB-UART в диспетчере устройств Windows.
2. Перед заменой заводской демонстрации можно сохранить копию Flash. В виртуальном окружении установите `python -m pip install esptool==4.9.0` или используйте esptool из пакета PlatformIO. Выполните `python -m esptool --chip esp32 --port COM7 flash_id`. Для подтверждённых 4 МиБ выполните `python -m esptool --chip esp32 --port COM7 read_flash 0x0 0x400000 factory-backup.bin`. Замените COM7 фактическим портом. Храните образ локально.
3. Выполните `pio run -e discovery-st7789 -t upload --upload-port COM7`, затем `pio device monitor -p COM7 -b 115200`. Должны появиться надпись **TV-4 DIGITAL**, четыре последовательно появляющихся прицела и полоса цветов слева направо красный, зелёный, синий.
4. Удерживайте центр каждого прицела до его перемещения, полностью отпускайте экран между точками. Первые три точки определяют поворот, зеркальность и масштаб, четвёртая проверяет ошибку по каждой оси (допуск 14 пикселей). Проведите стилусом вдоль всех краёв. Метки должны следовать за ним. В Serial выводятся исходные отсчёты, давление и экранные координаты. Буква `c` повторяет процедуру. Калибровка сохраняется отдельно для каждого профиля.
5. Если подсветка есть, но надпись или цвета неправильные, проверьте маркировку и повторите тест с `discovery-ili9341` для платы с тем же расположением сигналов. Если ни один вариант не проходит, нужны маркировка шлейфа и схема конкретной PCB. После успешного теста установите панель с тем же суффиксом профиля.
