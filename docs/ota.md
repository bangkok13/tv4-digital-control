# Локальная сеть и обновление

При отсутствии сохранённой сети панель открывает на 10 минут точку `TV4-xxxxxx` с уникальным паролем. Экран «Меню → Wi-Fi / OTA» показывает SSID, пароль точки, адрес и пароль администратора. «Настроить Wi-Fi» открывает точку повторно. Подключите телефон к ней, откройте показанный IP по HTTP, разверните раздел обслуживания и войдите пользователем `admin`. Введите SSID сети 2,4 ГГц и пароль. После подключения закройте точку на TFT, там появятся адрес STA и RSSI. Пустой пароль разрешён для открытой сети. Через тот же портал можно заменить ошибочные реквизиты. Для просмотра телеметрии авторизация не требуется.

Для обновления физически остановите и обесточьте привод, оставив панели отдельное питание. Выберите «Доступ OTA» на TFT и подтвердите отключение привода. Доступ открывается на пять минут. На стенде без фронтов с включения достаточно пяти секунд. После любого физического фронта выдерживается 65 секунд с учётом работы тахометра на 1 RPM. Действительное измерение вращения в LIVE также блокирует окно. Дальнейший фронт закрывает доступ даже в DEMO. Неподвижная мишень, обрыв и потеря питания датчика могут выглядеть одинаково. Ошибка контрольной суммы, обрыв загрузки и отмена до переключения слота оставляют предыдущее приложение загрузочным. После успешной проверки новая версия запускается с сохранённой NVS.

**Из браузера.** Введите SHA-256 приложения из `SHA256SUMS.txt` проверенного выпуска и выберите `panel-st7789.bin` для двухпортовой платы. Браузер показывает размер и прогресс передачи, TFT показывает прогресс записи. Для сборки PlatformIO файл называется `.pio/build/panel-st7789/firmware.bin`. Сервер принимает Digest-аутентификацию, токен CSRF в отдельном заголовке, точный размер и SHA-256. Страницы обслуживаются из Flash без CDN. Прошивка и хеш должны быть получены через доверенный канал.

**Из PlatformIO.** Задайте на локальном ПК переменные `TV4_OTA_HOST` (адрес из меню) и `TV4_OTA_PASSWORD` (пароль admin с панели). Выполните `pio run -e panel-st7789-ota -t upload`. Для Windows переменную пароля можно ввести без записи значения в историю терминала:

```powershell
$env:TV4_OTA_HOST = Read-Host 'IP панели'
$password = Read-Host 'Пароль OTA с панели' -AsSecureString
$env:TV4_OTA_PASSWORD = [Net.NetworkCredential]::new('', $password).Password
pio run -e panel-st7789-ota -t upload
Remove-Item Env:TV4_OTA_PASSWORD
```

ArduinoOTA использует аутентификацию и MD5 штатного протокола espota. Web OTA проверяет SHA-256. Криптографическая подпись издателя и аппаратный Secure Boot не включены в обычном выпуске. Не пробрасывайте HTTP или UDP 3232 в интернет. Используйте доверенную локальную сеть, HTTP не шифрует вводимый пароль домашней Wi-Fi. При повреждении образа или утере доступа восстановите профиль и таблицу через USB.
